Export instrument parts as SVG

Open an MSCX or MSCZ file to export it as one MusicXML file with every instrument part. You can also prepare its parts and export SVG pages, individually or together in a ZIP. Part pages are songbook sheets: ISO B6 landscape with the booklet header and footer. Processing stays in your browser.

What still needs review

A successful import does not prove that every note, font or layout detail was preserved. The following notices describe validation limits; they are not detected errors in your file.

    Instrument parts

    Existing linked parts are preserved. If none exist, preparation creates instrument parts; hidden instruments may be included.

        MIDI

        Exports a MIDI file for the full score and for each part, with repeats expanded, as desktop MuseScore does. Prepare the parts first for a file without saved parts.

          Full-score MusicXML

          Exports one MusicXML file containing every instrument part, with transpositions, keys and clefs. If the file has saved parts, the MusicXML is built from the full score, so part-only layout (breaks, spacing) is not included.

            MusicXML partNameInstrumentTranspositionSaved/catalog part

            Part pages

            Select parts above, then render their pages. Each part is drawn by Verovio from the full-score MusicXML. Tempo, jump and rehearsal markings are copied from the top part. Pages embed their fonts and use no external files.

            Spacing, system breaks and engraving differ from desktop MuseScore Studio 4.5.2, and saved-part layout is not used. Review the page previews before using these exports.
