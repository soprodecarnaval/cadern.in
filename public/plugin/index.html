Caderninho Formatter

O Caderninho Formatter é o plugin de MuseScore que desenvolvemos para auxiliar na formatação de partituras para o sistema cadern.in.

⚠️ ALERTA

Por enquanto, para subir a partitura no sistema do cadern.in TEM QUE SER NO MUSESCORE 3

Estamos no processo de migração para o MuseScore 4, mas por enquanto ainda não há suporte do sistema.

Como usar

Siga o tutorial aqui.

O plugin funciona da mesma maneira em ambas as versões do MuseScore.

Download

  • Musescore 3
  • Musescore 4

Instalação

Instruções para MuseScore 4, o processo é ser semelhante no MuseScore 3. O que deve mudar são os nomes das pastas e os caminhos de alguns menus.

  1. Ache a pasta de plugins do MuseScore:
    • 🪟Windows: C:\Users\SeuUsuário\Documents\MuseScore4\Plugins
    • 🍎Mac: ~/Documents/MuseScore4/Plugins/
    • 🐧Linux: ~/Documents/MuseScore4/Plugins/
    • Talvez seja necessário criar a pasta Plugins dentro da sua pasta do MuseScore
  2. Baixe o arquivo QML do plugin na seccao de download acima.
  3. Coloca o arquivo na pasta de plugins do MuseScore 4
  4. Abre o MuseScore 4 e vai no menu "Extensões". Se deu certo o nome do plugin já vai aparecer lá.
  5. (se o passo anterior não deu certo) Vai em "Extensões" → "Gerenciar Extensões…" e clica no botão "↻ Recarregar extensões". Se o arquivo .qml estiver na pasta correta o nome plugin vai aparecer ali perto do botão.
